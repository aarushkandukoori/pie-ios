# Pie on iOS — project site

One-page site for the Pie-on-iOS effort: Pie Voice (an on-device voice
assistant served by the embedded Pie engine), a scroll walkthrough of a
real Simulator session, an in-browser WebLLM recreation, and measured
benchmarks.

Live: https://aarushkandukoori.github.io/pie-ios/
Code: https://github.com/aarushkandukoori/pie/tree/ios-voice
